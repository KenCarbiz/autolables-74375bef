 4/19. CPO follows Used: a business rule, not a visual exception.
    - What it does: product_rules.condition stores one of new, used or all
      (migration 20260518100000_product_rules.sql, CHECK). There is no CPO
      value. Saving Used only stores "used"; New and Used stores "all". A
      CPO vehicle is treated as used. So a dealer cannot include CPO
      without Used, or exclude CPO while including Used.
    - On screen 07 the CPO box mirrors Used and is disabled; hovering it, or
      a screen reader, says "Certified pre-owned follows Used in the current
      rule model". In the Sample vehicle results a CPO vehicle is eligible
      exactly when Used is checked.
    - Existing behaviour: the three-value condition and the matcher
      (src/hooks/useProductRules.ts matchesRule) predate Administration V2
      (e5c1a60, 2026-09-09). V2 (587b2e3, 2026-10-28) added the visible,
      disabled CPO box; it did not create the rule.
    - Where the dealer sees or controls it: on this page, only through the
      Used checkbox (CPO cannot be set separately). In Administration >
      Pricing & Products > Applicability, the rule editor offers All, New
      only or Used only, with no mention of CPO. There is no setting that
      separates CPO.
    - Not changed in this review.

G. OPEN FINDING (reported, not changed; business-rule decision)
20. The Sample vehicle results description says the vehicles are "run
    through the same matcher the addendum uses". It is the same function
    (matchesRule), but the addendum builder (src/pages/Index.tsx:382)
    passes only year, make, model, trim and body style; it never passes
    the vehicle's condition or mileage. matchesRule skips a check whose
    input is missing.
    - So today a product rule's condition (New / Used / All) and maximum
      mileage are not applied when an addendum is built.
    - Screen 07's sample results do apply them.
    - The sample results can therefore show a vehicle as not eligible
      that the addendum would still include. Example from the fixture:
      2022 Example H20, CPO, 96,480 mi, against an 80,000 mi limit.
    This predates V2 and is outside visual acceptance. Fixing the
    addendum input or the wording is a separate decision.
