# MARKETCHECK_CAPABILITY_MATRIX

Status vocabulary (handoff §5): ACTIVE / SHADOW / ENTITLEMENT_BLOCKED /
AUTOCURB_RESERVED / NOT_USEFUL. "Entitled?" is what production has actually
answered, not what a plan sheet says: `answers` means a 2xx with usable data
in the last 30 days; `refused` means 401/403/429 or an empty 200 in the last
30 days; `untested` means never called from this account.

Endpoint column holds the current documented path from the handoff reference
(2026-10-21). Live contract verification is blocked from this environment
(see ENTITLEMENT_AND_TERMS_REPORT.md §4); paths marked `(ref)` are therefore
documented-not-verified.

Cost metadata is the 2026-08-01 public list price in `mcCost.ts`. It is an
operator estimate and must become configuration before any business rule
depends on it (§23). TTL values are the current code's behaviour, not the
target policy; targets are in NEW_VEHICLE_PROVIDER_POLICY.md and
USED_VEHICLE_PROVIDER_POLICY.md.
